# Verax Nutrition

Web de Verax Nutrition (nutrición deportiva por objetivo, empezando por la comida), hecha por Posiciona Alto (posicionaalto.com).

## Puesta en marcha

```bash
npm install
npm run dev
```

- Web: http://localhost:3000

## Comprobaciones

```bash
npm run tipos   # tipos de TypeScript
npm run build   # compila la web
```

## Publicación

La publicación en producción la hace Posiciona Alto tras revisar la versión de pruebas. Mientras `VERAX_INDEXAR` no sea `si`, todas las páginas llevan `noindex`.
